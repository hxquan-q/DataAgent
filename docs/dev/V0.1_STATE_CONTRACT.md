# DataAgent v0.1 状态与数据契约

本文档是 DataAgent v0.1 后续 worker 使用新增状态键和技能表的唯一引用源。

## 状态键

所有键均在 `DataAgentConfiguration.keyStrategyFactory` 中使用 `KeyStrategy.REPLACE`。列表和 Map 的累积更新由消费节点按“读出 → 追加 → 写回”完成。

| 键名 | Java 类型 | 用途 | 消费 worker |
|---|---|---|---|
| `SQL_HEAL_ERRORS` | `List<String>` | 保存 SQL 自愈各轮错误历史，供修复提示词读取全部历史错误 | sql-heal #13 |
| `CHART_IMAGE_MAP` | `Map<String, String>` | 保存分析步骤到 g2-ssr 图片 URL 的映射（`step -> imageUrl`） | chart-render #6 |
| `RESULT_SANITY_RETRY` | `Boolean` | 标记 SQL 结果合理性检查是否触发过有界重试 | sqlexec #14 |

## `skill` 表

存储可复用技能正文及其注入元数据。

| 字段 | 类型 | 约束/默认值 | 说明 |
|---|---|---|---|
| `id` | `INT` | 主键，自增 | 技能 ID |
| `name` | `VARCHAR(128)` | 非空 | 技能名称 |
| `description` | `VARCHAR(512)` | 可空 | 技能描述及适用时机 |
| `scope` | `VARCHAR(32)` | 非空；索引 `idx_scope_enabled(scope, enabled)` | 技能注入作用域 |
| `triggers` | `VARCHAR(512)` | 可空 | 逗号分隔的触发关键词 |
| `content` | `TEXT` | 非空 | 技能正文/指令 |
| `params_json` | `TEXT` | 可空 | 预留参数 JSON |
| `enabled` | `TINYINT` | 默认 `1` | `0` 禁用，`1` 启用 |
| `priority` | `INT` | 默认 `0` | 注入优先级，数值越大越先注入 |
| `display_order` | `INT` | 默认 `0` | 展示顺序 |
| `create_time` | `TIMESTAMP` | 默认 `CURRENT_TIMESTAMP` | 创建时间 |
| `update_time` | `TIMESTAMP` | 默认 `CURRENT_TIMESTAMP`，更新时自动刷新 | 更新时间 |

## `agent_skill` 表

保存智能体与技能的绑定关系；`agent_id` 使用 `INT`，与现有 `agent.id` 类型一致。

| 字段 | 类型 | 约束/默认值 | 说明 |
|---|---|---|---|
| `id` | `INT` | 主键，自增 | 绑定 ID |
| `agent_id` | `INT` | 非空；索引 `idx_agent(agent_id)` | 智能体 ID |
| `skill_id` | `INT` | 非空 | 技能 ID |
| `enabled` | `TINYINT` | 默认 `1` | `0` 禁用，`1` 启用 |
| `create_time` | `TIMESTAMP` | 默认 `CURRENT_TIMESTAMP` | 创建时间 |

`agent_skill` 通过唯一键 `uk_agent_skill(agent_id, skill_id)` 防止重复绑定。v0.1 契约不新增外键。

## `skill.scope` 取值约定

| 值 | 注入目标 |
|---|---|
| `report` | 报告生成提示词 |
| `sql` | SQL 生成/修复提示词 |
| `python` | Python 生成/分析提示词 |

v0.1 仅约定以上三个 scope。新增 scope 前必须先更新本契约，再由对应消费节点实现注入。
