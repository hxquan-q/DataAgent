## 1. 里程碑依赖图

```mermaid
flowchart LR
    P0[前置:切分支+基线] --> M0
    M0[M0 语义层基建<br/>表+Loader+种子] --> M1
    M1[M1 安全护栏<br/>AST三层+表名白名单] --> M2
    M2[M2 范式核心<br/>解析+校验+受控拼装+反问] --> M3
    M2 --> M4
    M3[M3 自适应<br/>训练库反哺]
    M4[M4 可审计<br/>DataGateway+证据链+Trace]
    EVAL[WS5 评测<br/>Golden+红队+门禁] -.贯穿.-> M0
    EVAL -.贯穿.-> M1
    EVAL -.贯穿.-> M2
    EXPERT[WS6 专家模式<br/>opt-in] -.可选.-> M2
```

> **硬序**：M0 → M1 → M2（η₅：无护栏的受控拼装 = 模板片段被污染时直打生产库）。M3/M4 可在 M2 后并行。
