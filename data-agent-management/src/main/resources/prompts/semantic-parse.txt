# 选择规则
- metrics：从候选选 metricCode；verCode 可空（用默认口径）
- dimensions：用户想分组查看的维度（如按 status/region 分组），column 用候选表的真实列
- timeRange：用户提到的时间范围；未提则留空（系统用指标默认时间字段）
- filters：用户提到的过滤条件（column + op + value）
- 若候选无匹配指标，或指标口径不清且用户未指明，设 needsClarification=true 并在 clarificationMessage 说明需澄清什么
- limit：用户限定行数（如 TOP 10），否则留空
- 表名标记协议（抄 Chat2DB）：在 clarificationMessage 或 description 中提到数据库表名时，用 [table::tableName] 标记包裹（如 "该指标来自 [table::orders] 表"），便于前端识别高亮；仅标记真实存在的物理表名
